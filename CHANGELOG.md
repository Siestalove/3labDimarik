# Changelog

## Исправления (последняя версия - v1.1)

### Исправлена логика принятия строк для любого состояния
- **Проблема**: Строка принималась только если автомат в состоянии q0 и стек содержит только Z
- **Решение**: Убрано ограничение на состояние - теперь строка принимается в **любом** состоянии, если входная строка обработана полностью и стек содержит только маркер Z
- **Результат**: Автоматы для разных языков (например, a^n b^n) теперь работают корректно

## Предыдущие исправления (v1.0)

### Исправлена логика работы стека
- **Проблема**: Символы в стеке добавлялись в неправильном порядке из-за лишнего `.reverse()`
- **Решение**: Убран `.reverse()` при добавлении символов в стек
- **Результат**: Строка "aabbaa" и другие палиндромы теперь корректно принимаются автоматом

### Улучшена визуализация результатов
- Убрано ограничение на показ только первых 4 путей - теперь показываются ВСЕ исследованные пути
- Изменен текст заголовка: "Всего исследовано путей: X" вместо "Исследовано альтернативных путей"
- Все альтернативные пути теперь доступны через раскрывающиеся блоки (details/summary)

### Улучшена логика принятия строк
- Строка принимается, если:
  - Входная строка обработана полностью (пустая)
  - Стек пуст ИЛИ состояние q0 и стек содержит только маркер Z
- Добавлена поддержка различных финальных состояний (не только q2)

### Улучшена визуализация шагов
- Добавлено сообщение о начальной конфигурации
- Улучшены сообщения об успешном завершении
- Более подробные сообщения об ошибках

## Тестирование

Все тесты проходят успешно:
- ✓ Палиндромы: "aabbaa", "aa", "bb", "abba"
- ✓ Пустая строка
- ✓ Отклонение непалиндромов: "abc", "ab", "aaa"

## Пример работы

Для строки "aabbaa":
1. (q0, aabbaa, Z) - начальное состояние
2. (q0, abbaa, [a, Z]) - применен переход (q0, a, Z) → (q0, aZ)
3. (q0, bbaa, [a, a, Z]) - применен переход (q0, a, a) → (q0, aa)
4. (q0, baa, [b, a, a, Z]) - применен переход (q0, b, a) → (q0, ba)
5. (q1, aa, [a, a, Z]) - применен переход (q0, b, b) → (q1, λ) (угадали середину!)
6. (q1, a, [a, Z]) - применен переход (q1, a, a) → (q1, λ)
7. (q1, ε, [Z]) - применен переход (q1, a, a) → (q1, λ)
8. (q2, ε, []) - применен переход (q1, λ, Z) → (q2, λ)
9. **ПРИНЯТА!** - стек пуст, строка обработана

Автомат корректно "угадывает" середину палиндрома через недетерминированный выбор на шаге 5.
