# ДМП-Автомат Визуализатор

Веб-приложение на React для визуализации работы детерминированного магазинного автомата (ДМП-автомата, PDA - Pushdown Automaton).

## 🎉 Последние обновления

- ✅ **Исправлена логика принятия строк** - строка принимается в любом состоянии, если вход обработан и в стеке только Z
- ✅ **Исправлена критическая ошибка в работе стека** - символы теперь добавляются в правильном порядке
- ✅ **Показываются ВСЕ исследованные пути** - больше нет ограничения в 4 пути
- ✅ **Улучшенная визуализация** - более подробные сообщения о каждом шаге выполнения

## Возможности

- **Интерактивная таблица переходов**: Добавляйте, редактируйте и удаляйте переходы автомата
- **Поддержка недетерминизма**: Автомат может иметь несколько переходов из одного состояния и исследует все возможные пути
- **Полная визуализация выполнения**: Пошаговое отображение работы автомата с состояниями, входной строкой и содержимым стека
- **Детальная диагностика**: При отклонении строки показывается причина и **все** исследованные пути (без ограничений)
- **Пример из задания**: Встроенный пример для проверки палиндромов

## Формат переходов

Переход задается в виде: `(fromState, inputSymbol, stackTop) → (toState, stackPush)`

Где:
- `fromState` - исходное состояние (например, q0)
- `inputSymbol` - входной символ или λ для пустого символа
- `stackTop` - символ на вершине стека (Z - начальный символ стека)
- `toState` - новое состояние
- `stackPush` - что записывается в стек (λ для удаления без записи)

## Пример использования

### Автомат для палиндромов

Распознает строки вида w·w^R, где w^R - обращение строки w.

**Переходы:**
1. (q0, a, Z) → (q0, aZ)
2. (q0, b, Z) → (q0, bZ)
3. (q0, a, a) → (q0, aa)
4. (q0, a, a) → (q1, λ)
5. (q0, a, b) → (q0, ab)
6. (q0, b, a) → (q0, ba)
7. (q0, b, b) → (q0, bb)
8. (q0, b, b) → (q1, λ)
9. (q1, a, a) → (q1, λ)
10. (q1, b, b) → (q1, λ)
11. (q1, λ, Z) → (q2, λ)

**Примеры строк:**
- ✓ `aabbaa` - принимается
- ✓ `abba` - принимается
- ✓ `aa` - принимается
- ✗ `abc` - отклоняется

## Установка и запуск

### Требования
- Node.js версии 16 или выше
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы будут в папке `dist/`

### Предварительный просмотр production сборки

```bash
npm run preview
```

## Как работает автомат

1. **Начальное состояние**: q0 с пустым стеком (содержит только Z)
2. **Обработка входа**: Автомат читает символы и изменяет состояние и стек согласно переходам
3. **Недетерминизм**: Если есть несколько возможных переходов, автомат исследует все ветви
4. **Принятие**: Строка принимается, если достигнуто конечное состояние (q2) с пустым стеком
5. **Отклонение**: Если ни один путь не привел к успеху, показывается причина
