# Краткое описание исправления

## Что было исправлено

Убрано ограничение на **состояние автомата** при принятии строки.

### До исправления ❌

Строка принималась **только** если:
- Входная строка обработана полностью (пустая)
- Стек содержит только маркер Z
- **Автомат находится в состоянии q0** ⚠️

Это приводило к тому, что автоматы для языков типа a^n b^n не работали, так как они заканчивают работу в состоянии q1, а не q0.

### После исправления ✅

Строка принимается если:
- Входная строка обработана полностью (пустая)
- Стек содержит только маркер Z ИЛИ стек пуст
- **Автомат может быть в ЛЮБОМ состоянии** (q0, q1, q2, ...) ✨

## Изменения в коде

**Файл:** `src/pdaSimulator.js`

**Строка 53:**
```javascript
// До:
if (input === '' && stack.length === 1 && stack[0] === 'Z' && state === 'q0')

// После:
if (input === '' && stack.length === 1 && stack[0] === 'Z')
```

Убрано условие `&& state === 'q0'`.

## Примеры работы

### Язык a^n b^n

Строка `"aabb"`:
- Финальное состояние: **q1**
- Финальный стек: **[Z]**
- Результат: **✓ ПРИНЯТА**

### Язык палиндромов

Строка `"aa"`:
- Финальное состояние: **q1** (после λ-переходов может быть и **q2**)
- Финальный стек: **[]** (пустой) или **[Z]**
- Результат: **✓ ПРИНЯТА**
