# Дедупликация Альтернативных Путей

## Проблема

При исследовании различных альтернативных путей в PDA симуляторе одинаковые пути могли добавляться в список результатов несколько раз. Это приводило к:

- Повторению одинаковых путей в списке альтернативных ветвей
- Неправильному подсчету количества уникальных путей
- Запутанности пользователя при просмотре результатов

## Решение

Добавлены два метода в класс `PDASimulator`:

### 1. `serializePath(path)`
Преобразует путь в уникальную строку-идентификатор для сравнения:
```javascript
serializePath(path) {
  return path.map(step => 
    `${step.state}|${step.input}|${(step.stack || []).join(',')}|${step.status}`
  ).join('::');
}
```

Включает в идентификатор:
- Текущее состояние (state)
- Оставшуюся входную строку (input)
- Содержимое стека (stack)
- Статус шага (status)

### 2. `deduplicatePaths(allPaths)`
Удаляет дубликаты из списка путей:
```javascript
deduplicatePaths(allPaths) {
  const seenPaths = new Set();
  const uniquePaths = [];
  
  for (const pathObj of allPaths) {
    const serialized = this.serializePath(pathObj.path);
    if (!seenPaths.has(serialized)) {
      seenPaths.add(serialized);
      uniquePaths.push(pathObj);
    }
  }
  
  return uniquePaths;
}
```

Использует `Set` для отслеживания уникальных путей и возвращает только неповторяющиеся пути.

## Применение

В методе `simulate()` после исследования всех путей:
```javascript
const uniquePaths = this.deduplicatePaths(allPaths);

return {
  accepted: result.accepted,
  path: result.accepted ? result.path : (uniquePaths.length > 0 ? uniquePaths[0].path : initialPath),
  allPaths: result.accepted ? [] : uniquePaths,  // <- используются уникальные пути
  reason: result.reason
};
```

## Результат

✅ Одинаковые пути больше не повторяются в списке альтернативных ветвей
✅ Правильный подсчет количества уникальных альтернативных путей
✅ Пользователь видит все исследованные пути без дубликатов
✅ Сообщение "Все возможные ветви исследованы, ни одна не привела к успеху" показывает только для действительно разных ветвей

## Тестирование

Проверены различные сценарии:
- Палиндромы с несколькими вариантами распределения символов
- Строки с несколькими альтернативными путями обработки
- Грамматики с недетерминизмом

Все пути теперь отображаются без дубликатов, и их количество соответствует действительному числу уникальных альтернативных путей.
